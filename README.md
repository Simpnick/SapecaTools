# Sapeca Tools — Distribuição oficial

Este repositório contém somente os instaladores oficiais, arquivos de atualização e notas de versão do Sapeca Tools.

O código-fonte não é distribuído aqui. Baixe sempre a versão mais recente pela página de [releases](https://github.com/Simpnick/SapecaTools/releases).

## Atualização no aplicativo

No Sapeca Tools, abra **Atualizações** e use **Buscar atualização**. O aplicativo consulta esta distribuição para verificar e baixar novas versões.

## Segurança

Instale apenas arquivos publicados nesta página de releases. Problemas de segurança podem ser relatados de forma privada ao desenvolvedor do projeto.
